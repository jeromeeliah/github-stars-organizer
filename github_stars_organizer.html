GitHub Stars Organizer

Review your starred repositories locally, tune the taxonomy, export clean files, and optionally try GitHub Lists sync.

Connect

Runs in this browser. The token is not stored and is only sent to GitHub API requests. Generate a fine-grained token at github.com/settings/personal-access-tokens/new. For reading stars, choose your account as the resource owner and enable Starring: Read. If you want private starred repositories included, allow repository access to the repositories you need.

How To Apply

1. Analyze your stars. 2. Use search, category filter, and Needs review only to narrow a subset. 3. Tick the repositories you want. 4. Apply a category to the selected subset or push that subset to one GitHub List if the experimental endpoint is available.
