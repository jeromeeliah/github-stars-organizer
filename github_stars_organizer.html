GitHub Stars Organizer

File unfiled stars in this browser and download JSON or Markdown.

Connect

Runs in this browser. The token is not stored and is only sent to GitHub API requests. Generate a fine-grained token at github.com/settings/personal-access-tokens/new. For reading stars, choose your account as the resource owner and enable Starring: Read. If you want private starred repositories included, allow repository access to the repositories you need.

How to use

1. Fetch stars or import github-stars-organized.json. 2. The inbox is the default (unfiled rows). 3. File a row to shrink the queue. 4. Export JSON to keep a copy. This browser may cache filings, never the token. 5. Subset push to GitHub Lists is experimental.

Custom category

Portable files

JSON is the reload file. This browser may keep filings. Never the token.

GitHub Lists

Lists sync is experimental and undocumented. Prefer subset push. Existing lists are reused by name.
