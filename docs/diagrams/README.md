# Current-state diagrams

Editorial HTML+SVG from [diagram-design](https://github.com/cathrynlavery/diagram-design), skinned with the app CSS tokens (`stars-cellar` profile). Open any file in a browser. No build step.

| File | Type | What it shows |
| --- | --- | --- |
| `architecture-current.html` | Architecture | Modules and the token trust boundary |
| `journey-review-desk.html` | User journey | Inbox path: RAM token → fetch → file sticky → export. Trough is the unfiled queue, not a wiped session |
| `loop-star-ocd.html` | Loop | Star → forget → search → despair → organize → star more |
| `story-map-cellar.html` | Story map | Fetch, review, file, export, optional Lists |
| `status-workstreams.html` | Story map | Shipped, now, and next |
| `taxonomy-layers.html` | Layer stack | Shelves vs facets vs granular vs signals (compact-granular) |

Brand: paper `#f6f3ee`, ink `#20211f`, accent `#176b55`. Size preset: `doc-wide`. Static, no motion.
