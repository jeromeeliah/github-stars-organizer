# OSS goal

A **local-first GitHub stars cellar** for people whose starring habit outran their ability to find anything.

Visible rules, one sitting that produces a file you keep, your taxonomy. Exports always work. Optionally file from `github.com` later via an extension. An optional **Cuvée** overlay may add rituals and BYO-key tasting notes. The core never requires Cuvée, a server, or a stored token.

## Honest claims

- No account. Token stays in RAM (and is never written to IndexedDB or exports).
- GitHub Lists push is optional and may fail. It is not the demo.
- No AI magic in v1. Keyword rules stay inspectable.
- Refresh must not erase filings. The cellar is the snapshot + taxonomy, not the PAT.

## Primary wedge

The **local web app**. Distribution may be GitHub Pages of the empty app; that is not a hosted product. The shareable artifact is a **wine-list Markdown** (no match-debug lines). JSON is the private reload file.

## What v1 is not

Not GitHub Star Lists with extra steps. Not a second brain. Not a SaaS dashboard. Cuvée stays an optional module you can delete.
