# Indie hacker review

2026-09-15. Positioning pass: would a stranger with 1k–3k stars finish in 20 minutes?

## One-liner (true)

Fetch your GitHub stars in the browser, sort them with rules you can see and edit, and download Markdown/JSON — no account, token stays in RAM, GitHub Lists push is optional and may not work.

## 20-minute done

A Markdown cellar file you believe roughly. Not “all stars live on GitHub Lists.”
